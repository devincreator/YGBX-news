# 《每周信息参考》版式参照记录（2026-10-16 文件版）

## 适用范围与安全边界

本记录根据用户在会话中提供的 `每周信息参考20261016.docx` **实际检查**形成，用于辅助 Word 输出与 QA。此处只保存**匿名化的版式结构与规则**，不将原始 Word、品牌图片、新闻正文、个人署名、商业内部内容上传 GitHub。

这份文件是**参考版，不是已经核对无误的母版**。本地生成新一期时优先在用户当期提供的实际原件复制件上改动，保持已有 XML 布局；若无可用本地原件，不应声称已经按原稿精确套版。

## 文档构造（已从 Word 包内容核查）

- 总体：A4 纵向 21 × 29.7 cm；上、下页边距各 2.54 cm；左右各 3.17 cm；页眉距离约 1.50 cm，页脚约 1.75 cm。
- 原稿有 **7 个 Word 分节**，包含首页封面、国内资讯目录与正文、附表、国际资讯目录与正文、封底等模块。页面显示约 17 页；自动分页可随文字变化。
- **封面**：阳光保险集团视觉主题、中文主标题及四个板块副标题、制作部门、日期、`年度第X期（总第Y期）`、国内/国际资讯起始页码；部分文本保存在**浮动文本框**而非普通段落。Word XML 中双轨图形表示可能导致同一可视文本抽取两次，替换时必须按可见形态确认，不能简单把所有重复 XML 文本替换成两个可见实例。
- **国内资讯目录**：`国内资讯`大标题、`目录`、4 个分类标题（`※保险行业`/`※监管动态`/`※经济与社会`/`※同业动态`），其下按 1—15 连续编号，带点线引导及页码；Word 含 `TOC`/`PAGEREF` 目录域（**可能有过期缓存**）。
- **国内正文**：每类用加粗的 `※板块` 起头；条目为**独立标题段落 + 独立正文单段**；序号 1—15 跨板块连续；标题加粗，正文段首缩进约 0.85 cm，结束标 `【来源名称】`。
- **附表**：国内正文后有 `附1：近一周国债收益率走势（单位：%）` 和 `附2：近一周H股上市保险公司股价变化（单位：港币）`，各含短文字介绍和数据表。第一张表为 **6 行×8 列**（日期 + 1/3/5/10/30年）；第二张为 **10 行×8 列**（日期 + 9 家H股保险公司），应使用实际交易日列。
- **国际资讯**：独立的 `国际资讯` 封面式标题页/目录；参考稿包含 `※国际市场`、`※国际保险`、`※数字科技` 三类，其序号重新从 1 开始；来源表述可为 `（新闻来源：XX）`，**不可把国内来源格式强加国际部分**。
- **封底**：单独的品牌视觉封底。保留所有形状、图片、分节符、页脚和页码域。

## 已观察到的字体/配色

| 对象 | 参考稿里的直接格式 |
|---|---|
| 国内新闻板块名与标题 | 微软雅黑，12 pt，加粗 |
| 国内新闻正文 | 微软雅黑，12 pt，普通字重；常见首行缩进约 0.85 cm |
| 国内/国际目录大标题 | 目录标题及目录级别分别使用版内既有样式（`toc 1`/`toc 2`），不要重建样式 |
| 附表表格 | Word `Table Grid`，首行橙色填充 **#F7873D**，表格直接字体多为 Times New Roman、10 pt；保留现有中文字体回退和加粗/对齐设置 |

以上是原文件的**实测特征**，并非跨平台固定字体强制要求。Word 和 LibreOffice 对文本框、目录、字体的呈现可能不同，交付必须重新渲染检查。

## 该参考版本已存在的 QA 问题（不能带入下一期）

1. **封面日期/文件名不一致**：文件名为 20261016，但封面仍显示 2026 年 10 月 09 日、2026 年第 34 期（总第 247 期）。生成正式版时，日期、期数与交付文件名要再次人工核对，期数不得擅自猜测递增。
2. **国内目录是过期缓存**：目录第1条显示“险资可投港股通 ETF…”，正文第1条却是“前8个月万能险保费近5000亿元…”；多条标题存在同类不一致。**所有目录项目都须与正文标题一一比对，更新目录域并核对页码**，不能只修改正文。
3. **附表文字与数据不同步**：附1文字仍写“截至10月8日，10年期收益率1.6797%”，而表头已延伸到10月15日，部分最后一日数据为空。将附表文字、表头日期、表内数据视作联动对象；使用确认过的同口径**官方日终数据**，无法核实时保留待更新，不得混合盘中/日终值或杜撰。
4. **国际资讯和国内资讯更新周期不同**：样稿中国际新闻报道日期早于国内新闻。除非用户明确要求同步更新国际版块，否则保留现有内容并提醒其时效，而非私自扩写或覆盖。
5. **字数不应从样稿反推规则**：部分新闻正文长度高于之前确认的 150–250 字目标；执行时仍优先遵照最新明确的编辑规范，遇用户提出以样稿篇幅为准时再变更该规则。

## 模板修改的可靠步骤

1. 对用户提供的真实 Word 做**本地复制**，不修改原件；
2. 用 Word 原有文本框/域/表格/段落节点完成有目标的替换，保留浮动对象及分节；
3. 先锁定新闻标题和编号，再刷新**国内目录域**和缓存，核对 1—15 的标题/页码；
4. 更新封面中的日期、期数、国内/国际目录起始页码及文档文件名；查明期数后再替换；
5. 附表按实际交易日、真实来源数据更新，并联动更新附表文案；数字精度取决于数据来源；
6. 如国际版块未纳入当期编辑范围，原样保留国际目录、正文、作者页和封底；
7. 渲染全部页面，核对目录、跨页标题、表格、文本框、页码和色块；只交付合格的本地 DOCX，不将文档内容推送仓库。

**关键结论**：原稿不是可以仅用 python-docx 的普通 `paragraph.text = ...` 批量替换的简单纯文本文件。模板操作须针对目录字段、浮动文本框和已有分节保留格式；如果自动替换损坏排版，应停止并转入人工定位/修复，不输出不可靠终稿。
